## IP 属性这一关：AkkoCloud 的 IP 注册在美国

上一节表格里“非原生（广播 IP）”这四个字，值得单独说清楚，因为它决定了这台机器能干什么、不能干什么。

有第三方测评机构对 AkkoCloud 伦敦 KVM-CN2-A1 mini 做过完整检测，IP 质量一栏的结论是“US broadcast IP”，也就是美国广播 IP；ISP 登记为 Kirino LLC，ASN 是 AS41378，Host 记录指向 HK CEDOC LIMITED，地理位置显示伦敦。翻译成人话：这台机器物理上在伦敦，但 IP 的注册主体是一家香港公司的美国广播段，不是英国本土宽带运营商分配的地址。

这意味着什么？建站、跑脚本、做代理落地、当跳板机，完全没问题，Google 和普通网站不会因为这个 IP 的注册地刁难你。但 TikTok、Netflix、ChatGPT 这类会查 IP 类型的平台，看到的是一台机房服务器，不是英国家庭宽带。拿它注册英区账号，风控通过率跟住宅 IP 不是一个量级。

要英国本土身份，只能看双 ISP 住宅那一档。CStoneCloud 伦敦节点用的是英国本土服务商的双 ISP 住宅 IP，双十一促销价 $6.59/月，配置 1 核 1G、20G SSD、2048GB 流量、300Mbps；丽萨主机用的是英国本土宽带运营商 Virgin Media O2 的家宽 IP，入门版 68 元/月，1 核 1G、10G NVMe、6T 月流量、300Mbps，第三方测评记录它能解锁 Netflix、BBC iPlayer、ITV Hub、BritBox 等一批英区流媒体。

## 三条写在条款里、买之前容易忽略的限制

**不设退款。** 第三方测评在引用商家服务条款时写明：无退款政策，若因商家原因无法提供服务，退款只退到账户余额，不退回原支付渠道。这跟丽萨主机的 48 小时无条件退款、CStoneCloud 的 24 小时退款（限 IP 未被墙、未滥用）、Kamatera 的 30 天免费试用完全不同。AkkoCloud 相当于买定离手，所以先用测试地址探一探线路再下单，比事后扯皮划算。伦敦机房的 Looking Glass 是公开的，可以自己测延迟和路由。

**标称 500Mbps，回国单线程跑不满。** 第三方测评的 iPerf3 测试记录显示，本地单线程 TCP 达不到标称的 500Mbps 峰值，回国方向的单线程速度在 100Mbps 上下。这个数字对建站、传输文件够用，但如果你的用途是长期大流量回传，得按 100Mbps 而不是 500Mbps 做容量规划。同一份测评里，CPU 是 Intel Broadwell 架构、单核 Geekbench 5 得分 413，属于轻量任务够用、重负载吃力的水平。

**回程是三网混合，不是全程 CN2 GIA。** 宣传口径写“三网 CN2 GIA 回程”，实测路由显示电信和联通回程走 CTG / CN2 GIA，移动回程走 CMIN2，去程移动走 CMIN2、联通走 10099、电信走 CN2 / CTG GIA。CN2 GIA 加 CMIN2 都是国内优化线路，实际体验不会差，但如果你特别在意移动线路是不是纯 GIA，心里要有数。

## 常见问题

**60 元以内能不能买到英国原生 IP？**

能。六六云 45 元/月那一档给的就是原生 IP，1 核 1G、15G 存储、520GB 流量、100Mbps，三网回程电信联通走 AS9929、移动走 CMI，支持支付宝。代价是最低配流量只有 520GB，跑大流量业务得往上加钱。如果“原生 IP”还不够、必须要住宅属性，起步价会跳到 49.5 元（CStoneCloud 双十一价）到 68 元（丽萨主机）。

**CN2 GIA 和 AS9929 哪个快？**

没有同环境、同时段的对比数据，给不出谁更快的结论。两家都是国内优化线路，方向不同：AkkoCloud 是三网回程 CN2 GIA 加移动 CMIN2，六六云是电信联通 AS9929 加移动 CMI。第三方测评记录六六云英国机全国三网平均 Ping 188ms，其中电信 236ms、联通 165ms、移动 163ms；AkkoCloud 这边公开测评没有给出可比的延迟数字，只给了路由和带宽结果。真要比较，拿两家的测试地址在自己网络环境里各 ping 一轮，比看别人的数字准。

**续费会涨吗？**

看商家。循环折扣的商家续费同价，首期折扣的商家第二年回原价。AkkoCloud 目前没有公开的循环折扣说明，低价来自年付定价本身；CStoneCloud 明确标注年付折扣是循环的；丽萨主机的长期折扣码是永久九折。下单前把“续费价”这三个字直接问客服，比看活动页靠谱。

**支付宝能付吗？**

AkkoCloud、六六云、丽萨主机、CStoneCloud、JustHost、Evoxt 都支持支付宝。Kamatera 不支持，只能信用卡。对没有双币信用卡的读者，这一条就能筛掉一半选项。
